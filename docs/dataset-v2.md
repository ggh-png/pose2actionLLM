## 이전 정면 v2 실험 스냅샷

아래 다운로드·검사 결과·100개 개별 링크는 Qwen3-4B 11% 평가에 사용한 **이전 v2** 입력입니다.
현재 v4와 같은 ID를 사용하지만 모든 자세의 시점과 좌표가 다릅니다.

2026-11-03의 v2 평가 당시 입력 100개를 정리했습니다.
생성기 v2, seed 42, 정면·비반전 기준이며 클래스별 25개입니다.
실제 사람이 측정한 좌표가 아닌 기능 검증용 합성 데이터입니다.

| ID | 클래스 | 개수 |
|---|---|---:|
| 0 | SITTING_HAND_DOWN | 25 |
| 1 | SITTING_HAND_UP | 25 |
| 2 | STANDING_HAND_DOWN | 25 |
| 3 | STANDING_HAND_UP | 25 |

입력은 좌우 어깨·팔꿈치·골반·무릎의 8개 관절이며 정규화 좌표를 사용합니다.
`HAND_UP`은 같은 쪽 어깨보다 팔꿈치가 높은지를 뜻하는 대리 기준입니다.
[LLM 실험 결과](experiment-results-v2.md)를 함께 확인하세요.
