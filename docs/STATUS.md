# 개발 상태와 진행 로그

아래는 현재 프로젝트의 실험 상태를 빠르게 파악할 수 있도록 정리한 요약입니다. 각 항목은 최신 결과를 기준으로 관리하고 있으며, 문서와 산출물은 GitHub Pages로 보관됩니다.

## 1. 현재 상태

- 로컬 검증: Python 3.12에서 pytest 통과, Ruff 통과, MkDocs strict build 통과
- 합성 데이터: v4 측면 100개 세트, 클래스별 25개씩 구성
- 모델 평가: 텍스트 모델 기록 유지 + VL 모델 비교를 추가 확장
- 문서화: 결과 해석, 재현 방법, 산출물 링크를 정리 완료

## 2. 핵심 실험 결과

| 시점 | 실험 | 결과 |
|---|---|---|
| 2026-11-03 | Qwen3-4B 정면 v2 | 11 / 100 (11%) |
| 2026-11-03 | 사용자 지정 프롬프트 비교 | Qwen3-8B 33%, Qwen3-4B 27%, Llama 25% |
| 2026-11-04 | 수치 규칙 프롬프트 비교 | Qwen3-8B 37%, Qwen3-4B 25%, Llama 25% |
| 2026-11-04 | Qwen3-VL-8B PNG+JSON 비교 | JSON 42% → PNG+JSON 44% |
| 2026-11-04 | VL 모델 비교 | Qwen3-VL-8B 90%, InternVL3.5 51%, Idefics3 36% |
| 2026-11-04 | Qwen3-VL-4B 추가 실험 | 확대 골격 + PNG+JSON 55% |

## 3. 지금까지의 결론

- 가장 강한 결과는 **Qwen3-VL-8B-Instruct의 확대 골격 PNG+JSON 조건**이었습니다.
- 4B 모델도 비슷한 흐름을 따라가며, **확대 골격 + JSON 조합이 가장 유효**했습니다.
- 다만 `HAND_UP` 계열 분류는 여전히 약하며, 그 부분이 현재 병목입니다.
- 실제 사람 자세 데이터로의 일반화는 아직 검증하지 않았습니다.

## 4. 구현 범위 완료

- 8개 관절 명시적 검증
- JSON/JSONL/CSV/dict 입력 처리
- 전처리, feature 추출, 렌더링 기반 시각화
- mock 평가 / 실제 VL 평가 / 혼동행렬 / 실패 집계
- FastAPI, CI 검증, 문서 빌드 자동화

## 5. 남은 과제

1. 실제 관측 pose 데이터 검증
2. `HAND_UP` 분류를 개선하는 프롬프트 또는 렌더링 재설계
3. 4B와 8B를 함께 정리한 최종 비교표 작성
4. 실제 모델 서버 운영 환경과 배포 경로 정리
