# 추가 실험 결과 · Qwen3-VL-4B-Instruct 확대 골격

2026-11-04에 수행한 추가 실험은 같은 합성 100개 세트에서, Qwen3-VL-4B-Instruct를 확대 골격 조건으로 다시 평가한 결과입니다. 비교 대조는 동일한 데이터에 대해 `json_only`, `png_only`, `png_json`을 같은 서버 환경에서 검증한 것입니다.

## 실험 요약

| 조건 | 정확도 | 정답 수 / 전체 | 실패 수 | 평균 지연 |
|---|---:|---:|---:|---:|
| JSON만 | 0.37 | 37 / 100 | 0 | 0.035 s |
| 확대 PNG만 | 0.43 | 43 / 100 | 0 | 0.056 s |
| 확대 PNG + JSON | 0.55 | 55 / 100 | 0 | 0.050 s |

결과적으로 가장 높은 성능은 `png_json` 조건이었습니다. 확대 골격 이미지에 JSON을 함께 넣는 조합이 4B에서도 가장 안정적으로 좋았고, 기존 규칙 기반 스타일보다 두드러진 차이를 보였습니다.

## 전체 해석

- `json_only` 37%: 4B는 좌표만으로는 앉기/서기와 팔 올림 구분을 모두 안정적으로 못 했습니다.
- `png_only` 43%: 이미지 자체는 앉기/서기 판단을 어느 정도 보완했지만, `SITTING_HAND_UP`과 `STANDING_HAND_UP`이 거의 구분되지 않았습니다.
- `png_json` 55%: 이미지와 JSON을 함께 제공했을 때 가장 좋은 성능을 보였고, 특히 `SITTING_HAND_DOWN`에서 강한 개선을 확인했습니다.

요약하면, 4B에서는 **확대 골격 + JSON 조합이 가장 유효**했습니다. 다만, `HAND_UP` 계열의 분류는 아직 약하게 남아 있어, 프롬프트나 이미지 표현을 더 세밀하게 다듬어야 합니다.

## 클래스별 지표

| 클래스 | Precision | Recall | F1 | 유효 표본 |
|---|---:|---:|---:|---:|
| SITTING_HAND_DOWN | 0.6667 | 0.9600 | 0.7869 | 25 |
| SITTING_HAND_UP | 1.0000 | 0.2000 | 0.3333 | 25 |
| STANDING_HAND_DOWN | 0.4386 | 1.0000 | 0.6098 | 25 |
| STANDING_HAND_UP | 0.5000 | 0.0400 | 0.0741 | 25 |

핵심 관찰은 다음과 같습니다.

- `SITTING_HAND_DOWN`은 비교적 잘 잡혔습니다.
- `STANDING_HAND_DOWN`은 높은 recall를 보였지만, 정확도는 제한적이었습니다.
- `HAND_UP` 클래스는 특히 `SITTING_HAND_UP`과 `STANDING_HAND_UP`를 구분하는 데 약했습니다.

즉, **앉기/서기와 팔 내림 분류는 실험적으로 충분히 보이며, 팔 올림 분류가 여전히 병목**입니다.

## 혼동행렬

행은 정답, 열은 예측입니다.

| 정답 / 예측 | 0 | 1 | 2 | 3 |
|---|---:|---:|---:|---:|
| 0 | 24 | 0 | 1 | 0 |
| 1 | 12 | 5 | 7 | 1 |
| 2 | 0 | 0 | 25 | 0 |
| 3 | 0 | 0 | 24 | 1 |

이 혼동행렬에서 `STANDING_HAND_DOWN`은 거의 모두 판별했고, `STANDING_HAND_UP`은 대부분 `STANDING_HAND_DOWN`으로 전환되는 경향을 보였습니다. `SITTING_HAND_UP` 역시 `SITTING_HAND_DOWN`과 혼재되는 비율이 높았습니다.

## 실험 조건

| 항목 | 값 |
|---|---|
| 모델 | Qwen/Qwen3-VL-4B-Instruct |
| 데이터 | 합성 100개, 4개 클래스 균등 25개씩 |
| 서버 | remote vLLM OpenAI 호환 endpoint |
| 입력 형식 | `json_only`, `png_only`, `png_json` |
| 이미지 스타일 | 확대 골격, 축/격자/텍스트 제거 |
| 프롬프트 | 모양 중심 지시문 v2 공유 |
| 평가 | zero-shot, temperature 0, max_tokens 256 |

## 결론

이번 4B 실험은 8B보다 낮은 절대 점수지만, **확대 골격 렌더링 + JSON 결합이 가장 나은 조건**이라는 점을 확인한 의미 있는 추가 실험이었습니다. 특히 손이 아닌 팔꿈치 기준의 `HAND_UP` 판정이 남은 한계로 보이므로, 다음 단계는 `HAND_UP`을 더욱 분리해서 지시하는 프롬프트 재설계와 8B 비교를 병행하는 것이 가장 합리적입니다.
