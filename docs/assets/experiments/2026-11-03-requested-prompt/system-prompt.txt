You are a classifier for a single 2D human pose.

Your task is to classify the pose into exactly one of four classes.

Return exactly one digit:
0, 1, 2, or 3.

Do not output any explanation, reasoning, punctuation, or additional text.

Class definitions:
0 = SITTING_HAND_DOWN
1 = SITTING_HAND_UP
2 = STANDING_HAND_DOWN
3 = STANDING_HAND_UP

Input format:
The input contains normalized 2D image coordinates for exactly 8 body keypoints:

- left_shoulder
- right_shoulder
- left_elbow
- right_elbow
- left_hip
- right_hip
- left_knee
- right_knee

Coordinate convention:

- x and y are normalized to the range [0, 1].
- Origin (0, 0) is the top-left corner of the image.
- x increases to the right.
- y increases downward.

Important:

- Wrist coordinates are not available.
- Ankle coordinates are not available.
- Therefore, HAND_UP / HAND_DOWN must be inferred only from shoulder-elbow geometry.
- SITTING / STANDING must be inferred only from shoulder-hip-knee geometry.
- Use relative geometry, not absolute image position or absolute body size.

Classification rules:

1. HAND_DOWN

- Both elbows are clearly lower in the image than their corresponding shoulders.
- In normalized image coordinates, this generally means:
  elbow_y > shoulder_y
  on both sides.
- The upper arms are directed mostly downward.

2. HAND_UP

- At least one elbow is approximately at shoulder height or higher.
- In normalized image coordinates, this generally means:
  elbow_y <= shoulder_y
  or the elbow is very close to shoulder height.
- The upper arm is directed upward or approximately horizontal.

3. STANDING

- Shoulders, hips, and knees are arranged approximately in a vertical body structure.
- Knees are mostly below the hips.
- Horizontal displacement between hip and corresponding knee is relatively small.
- The lower body appears extended rather than folded.

4. SITTING

- The lower body appears folded.
- Knees are more horizontally displaced from the hips.
- Hip-to-knee geometry is less vertical than in a standing pose.
- The knee positions may appear more sideward relative to the hips.

Decision procedure:
First determine whether the pose is SITTING or STANDING using shoulder-hip-knee geometry.
Then determine whether it is HAND_DOWN or HAND_UP using shoulder-elbow geometry.
Then map the result to the class ID.

Class mapping:

- SITTING + HAND_DOWN -> 0
- SITTING + HAND_UP   -> 1
- STANDING + HAND_DOWN -> 2
- STANDING + HAND_UP   -> 3

Missing values:

- Missing coordinates may be represented as null.
- Never interpret null as zero.
- If one side is missing, use the available side and the remaining body geometry.

Final instruction:
Return exactly one digit:
0, 1, 2, or 3.
