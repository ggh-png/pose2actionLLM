# 합성 Pose 데이터: 앉기·서기 모두 측면

현재 예시는 좌우 어깨·팔꿈치·골반·무릎 8개 관절만 포함합니다.
`synthetic_100.jsonl`은 클래스별 25개, 총 100개이며 `synthetic_100/`의 각 JSON·PNG와 일대일로 대응합니다.
`manifest.json`에 ID, 클래스, 상대 JSON/이미지 경로가 있습니다.

- `generator_version: 4`, `view: side_unmirrored`: 상체와 다리 모두 측면 시점입니다.
- 3D 관절 도식을 정면 기준 85~88도에서 정사영하여 2D 좌표를 만듭니다.
  좌우 어깨·골반이 거의 겹치며, 관절을 구별할 수 있도록 정확히 90도에서는 조금 벗어납니다.
- 앉기 50개는 허벅지가 앞으로 뻗고, 서기 50개는 아래로 향합니다.
- `facing_direction`은 화면 기준 `image_left` 또는 `image_right`이며 각각 50개입니다.
  앉기·서기 각각에서도 두 방향이 25개씩입니다. `camera_yaw_degrees`에 부호 있는 시점을 기록합니다.
- 좌우는 해부학적 이름을 유지합니다. 측면에서는 좌우를 화면 x좌표 순서로 판단할 수 없습니다.
- 실제 측면 영상에서 가려질 수 있는 먼 쪽 관절도 합성 입력에는 포함합니다. 가림 검출을 모사하지 않습니다.
- 손 올림 클래스명은 유지하지만 실제 기준은 팔꿈치가 같은 쪽 어깨보다 높은지입니다.

모든 데이터는 합성 도식이며 실제 카메라의 측정값이 아닙니다. 사람·카메라·앉은 자세에 따라
2D 형태가 달라지고, 8개 관절만으로 앉기/서기가 모호할 수 있습니다.
분류 성능 평가에는 실제 데이터를 별도로 수집하세요.

재생성: `python scripts/generate_synthetic_dataset.py --per-class 25 --seed 42`

이전 Qwen3-4B 11% 결과는 정면 v2 데이터에 대한 값입니다. 그 입력 스냅샷은
`docs/assets/experiments/2026-11-03/synthetic_100.jsonl`에 보존합니다. 새 v4는 아직 LLM 평가하지 않았습니다.

`sample.json`(서기·팔 내림), `pixel.json`(서기·팔 올림), `poses.jsonl`과 `poses.csv`(클래스별 하나)도 정면 기준의 작은 입력 예시입니다.
