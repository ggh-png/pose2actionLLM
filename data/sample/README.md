# 정면 합성 Pose 데이터

현재 예시는 좌우 어깨·팔꿈치·골반·무릎 8개 관절만 포함합니다.
`synthetic_100.jsonl`은 클래스별 25개, 총 100개이며 `synthetic_100/`의 각 JSON·PNG와 일대일로 대응합니다.
`manifest.json`에 ID, 클래스, 상대 JSON/이미지 경로가 있습니다.

- `view: front_unmirrored`: 정면 비반전 카메라 가정. 해부학적 왼쪽은 화면 오른쪽입니다.
- `generator_version: 2`: 기존의 비스듬한 측면/한쪽 무릎 이동 방식은 교체했습니다.
- 앉은 자세는 각 골반 아래로 조금 벌어진 무릎과 짧은 골반–무릎 투영 길이로 도식화했습니다.
- 선 자세는 골반–무릎 투영 길이를 더 길게 설정했습니다.
- 손 올림 클래스명은 유지하지만 실제 기준은 팔꿈치가 같은 쪽 어깨보다 높은지입니다.

모든 데이터는 합성 도식이며 실제 카메라의 측정값이 아닙니다. 사람·카메라·앉은 자세에 따라
2D 형태가 달라지고, 8개 관절만으로 앉기/서기가 모호할 수 있습니다.
분류 성능 평가에는 실제 데이터를 별도로 수집하세요.

재생성: `python scripts/generate_synthetic_dataset.py --per-class 25 --seed 42`

`sample.json`(서기·팔 내림), `pixel.json`(서기·팔 올림), `poses.jsonl`과 `poses.csv`(클래스별 하나)도 정면 기준의 작은 입력 예시입니다.
